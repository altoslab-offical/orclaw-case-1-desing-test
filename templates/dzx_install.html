SELF-HOSTED INSTALLATION

VPS
安装教学

从一台全新 VPS 到完整运行的大闸蟹 AI 助理，手把手完整安装教学。

⚠ 开始前请确认
  • — 一台 VPS（Ubuntu 22.04 LTS 推荐，至少 1GB RAM）
  • — 能 SSH 连线到你的伺服器
  • — 已取得 AI API Key（如 Gemini、DeepSeek 等）
  • — 已取得 Telegram Bot Token（向 @BotFather 申请）
/01 初始设定 /02 Node.js /03 安装套件 /04 初始化设定 /05 安装技能 /06 systemd /07 测试
/01
Step 01

初始伺服器设定

SSH 连线到你的 VPS 并更新套件列表，确保系统环境就绪。

bash 
# 连线到你的 VPS（替换为你的 IP）
ssh root@YOUR_SERVER_IP
bash 
# 更新套件列表（只更新列表，不全面升级以节省时间）
apt-get update -y
bash 
# 安装必要基础工具
apt-get install -y curl wget git build-essential
/02
Step 02

安装 Node.js 20

龙虾（OpenClaw）基于 Node.js 运行，需要 Node.js 18 或以上版本。推荐使用官方 NodeSource 源安装 Node.js 20 LTS。

bash 
# 安装 NodeSource 源
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
bash 
# 安装 Node.js
apt-get install -y nodejs
bash 
# 确认安装成功
node --version   # 应显示 v20.x.x
npm --version    # 应显示 10.x.x
✅

看到版本号出现就代表安装成功。Node.js 20 LTS 是目前最稳定的选择，支援到 2026 年 4 月。

/03
Step 03

安装龙虾核心套件

OpenClaw 是龙虾的核心引擎；ClaWHub 是技能管理工具，用来安装和管理各种功能技能。

bash 
# 全域安装（需要 root 或 sudo）
npm install -g openclaw clawhub
bash 
# 确认安装成功
openclaw --version
clawhub --version
⚠
出现 EACCES 权限错误？ 执行以下指令修正 npm prefix 后重新安装：
bash 
npm config set prefix '/usr/local'
npm install -g openclaw clawhub
/04
Step 04

初始化并设定 API Keys

建立设定目录并完成龙虾初始化设定，填入你的 AI API Key 和 Telegram Bot Token。

bash 
# 建立设定目录
mkdir -p /root/.openclaw
bash 
# 初始化设定（互动式）
openclaw init
💡
执行后会互动式询问你：
· AI Provider（选择 gemini / openai / anthropic / deepseek 等）
· AI API Key
· Telegram Bot Token
· 其他进阶设定（可直接按 Enter 跳过）
或者手动建立设定档
bash 
# 手动建立设定档
cat > /root/.openclaw/config.json << 'EOF'
{
  "ai": {
    "provider": "gemini",
    "api_key": "YOUR_GEMINI_API_KEY",
    "model": "gemini-2.0-flash"
  },
  "telegram": {
    "bot_token": "YOUR_BOT_TOKEN"
  },
  "streaming": false,
  "tools": {
    "deny": []
  }
}
EOF
⚠

记得将 YOUR_GEMINI_API_KEY 和 YOUR_BOT_TOKEN 替换为你实际的值。设定完成后这个档案请妥善保管，不要公开分享。

/05
Step 05

安装推荐技能

大闸蟹建议安装以下 9 种技能，覆盖日常所需的搜寻、天气、股票、加密货币等功能。

bash 
# 安装不需要 --force 的技能
clawhub install ddg-web-search weather summarize translate youtube-transcript
bash 
# 安装需要 --force 的技能（VirusTotal 误判，安全可用）
clawhub install --force skill-creator stock-info-explorer news-summary crypto-market-data
📦
为什么需要 --force？ 部分技能的脚本可能被 VirusTotal 等安全扫描工具误判。这些技能完全安全，加上 --force 旗标仅是告诉 ClaWHub 跳过安全警告继续安装。
🔧
stock-info-explorer 需要额外安装 uv（Python 环境管理工具）：
bash 
# 安装 uv（stock-info-explorer 的 Python 依赖）
curl -LsSf https://astral.sh/uv/install.sh | env HOME=/root sh
ln -sf /root/.local/bin/uv /usr/local/bin/uv
/06
Step 06

设定 systemd 服务

透过 systemd 服务让龙虾在伺服器重启后自动启动，并在崩溃时自动重启。

bash 
# 建立 systemd service 档案
cat > /etc/systemd/system/openclaw.service << 'EOF'
[Unit]
Description=OpenClaw AI Agent
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root
ExecStart=/usr/local/bin/openclaw start
Restart=always
RestartSec=10
Environment=HOME=/root

[Install]
WantedBy=multi-user.target
EOF
bash 
# 启用并启动服务
systemctl daemon-reload
systemctl enable openclaw
systemctl start openclaw
bash 
# 确认服务状态
systemctl status openclaw
✅

看到 Active: active (running) 表示成功！

/07
Step 07

测试你的大闸蟹

一切设定完成后，打开 Telegram 测试你的 AI 助理是否正常运行。

1

打开 Telegram，搜寻你的 Bot username

2

传送 /start 开始对话

3

试试说「你好」或「今天天气如何？」

4

如果有回应，恭喜！安装成功 🎉

常见问题排查

Bot 没有回应 → 确认 Bot Token 正确，确认服务正在运行（systemctl status openclaw）

API 错误 → 确认 API Key 正确且有剩余额度

服务崩溃 → 查看日志（journalctl -u openclaw -f）

权限问题 → 确认以 root 身份执行，或使用 sudo

查看日志
bash 
# 查看即时日志
journalctl -u openclaw -f

# 查看最近 100 行日志
journalctl -u openclaw -n 100
